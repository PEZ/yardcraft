# Design suggestions

Put durable suggestion overlays here as EDN files (not survey truth).

Populate after you have a Base design. See the `yardcraft-design-suggestions` skill:

1. Iterate in the REPL with `show!` / `show-base!`
2. When happy, write an EDN file under this directory
3. Rebuild via `ensure-site!` / suggestion APIs as documented in the skill

This directory starts empty on purpose.
