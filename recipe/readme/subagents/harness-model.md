# Harness / setup model

Design constraints for how Yardcraft setup orients across editors. The live model itself is in `AGENTS.md` (harness adapter + connect) and `yardcraft-setup` (workflow); connect depth in the `basilisp-blender` skill.

## Depth budget

VS Code family gets prescriptive verified steps; non-VS-Code gets ~5 goal-based lines, ever.

## Non-goals

- No README rewrite or second example chat for harness coverage.
- No Emacs/CIDER/monroe/inf-clojure how-tos — wing means wing.
- No alternate Clojure clients on VS Code family; no Backseat “peers”.
- No renaming of the `basilisp-blender` connect sequence, session keys, or `.vscode/settings.json` contents.
